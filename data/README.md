# AI Document QA Reviewer

This project contains two types of files.

## reference_docs

These are the source-of-truth documents. They contain approved product information and the rules that content should follow, including product behavior, plan limits, security wording, writing rules, compliance requirements, and the QA rubric.

Use these files when checking whether a statement in a draft is correct and properly supported.

## drafts_to_review

These are the documents that need to be reviewed. Some parts are correct. Some contain factual mistakes, unsupported claims, missing conditions, or writing problems.

The goal is not to flag everything. A draft should only be flagged when there is a clear problem that can be supported by the supplied reference material.

The reference docs are the approved product information and QA rules provided for this project. The drafts to review are the documents that need checking.
